# VerPinG v1.0.1 发行包

clash-verge-rev 节点延时自动切换工具：定时实测当前节点延时，超阈值自动换同国家低延时节点；全都超阈值就切全组最低并提醒一次，然后继续巡检。

## 本版更新

- **秒切**：历史中存在达标节点时，先实时复测最优候选，通过即立即切换，省去整组扫描
- **更快的检测**：单次测速超时 5s→2s，并发测速 4→8
- **历史自动过期**：超过有效期的延时样本自动作废并重测，历史每几个周期自动重置，避免用旧数据决策
- 修复周期性系统「默认响声」（日志面板滚动触发）
- 修复误判「全坏」而弹窗的问题

## 安装版用法

1. 运行 `VerPinG-Setup-1.0.1.exe`，按需勾选「开机自启」。
2. 首次启动会弹出设置面板：确认 API 地址（默认 `http://127.0.0.1:9090`）、密钥、目标策略组，点「保存设置」。
   - 密钥在 clash-verge-rev「设置 → 基础设置 → 外部控制器」里看。
   - 面板「测试连接」可一键验证：显示内核版本与策略组数量即正常。
3. 右下角托盘出现图标：左键单击打开面板，右键可隐藏/退出。

## 便携版用法

1. 解压 zip，运行 `VerPinG.exe`（`icon.ico` 须与 exe 放同一目录，zip 里已带）。
2. 同上确认设置并保存；配置存 `config.json`，日志存 `logs\app.log`，都在 exe 同目录，面板「日志目录」按钮直达。

## 提示

- `test_mode`（静默模式）只屏蔽弹窗，切换照常执行；全坏时切最低延时节点并提醒一次（无声）。
- 仅在系统代理开启时工作；关闭窗口只会最小化到托盘，不会退出。
